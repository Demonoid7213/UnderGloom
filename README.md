# UnderGloom

An enclosed underground exploration game with infinite chunk loading and mysterious flora.

## How to Play

Open `index.html` in your web browser to start exploring the depths of UnderGloom.

### Controls
- **Arrow Keys** or **WASD** - Move around
- Explore the infinite underground world filled with mushrooms, glowing plants, and valuable ores

## Features
- Infinite procedurally generated world (extends infinitely left and right)
- Dynamic chunk loading system for smooth performance
- Atmospheric dark aesthetic with eerie colors
- Multiple terrain types: Mire Clay, Stone, Ores (Coal & Iron), Mushrooms, Glowing Plants
